2. Description of the Protocol

LibertyTorch is a decentralized, non-custodial raffle protocol built on the Robinhood Chain (chain ID 4663). The Protocol consists of:

  • The LibertyVault — a smart contract that accepts ERC-20 token deposits and calculates weighted raffle entries.
  • The LibertyRaffle — a smart contract that conducts hourly weighted random drawings.
  • The LinkRegistry — a smart contract that links primary and secondary wallet addresses.
  • The $LIBERTY token — an ERC-20 token on Robinhood Chain.

Once deployed, the Protocol runs autonomously on Robinhood Chain. No operator, developer, or entity controls, manages, or can reverse transactions on the Protocol.
